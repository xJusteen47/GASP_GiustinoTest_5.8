## 2. Recommendation for TL_Overlord_Jab2
Data-only path that works today = montage root motion (C). No timeline property needed: author the root translation in the AnimSequence, set Enable Root Motion on the AnimSequence. In _anim_and_montage after anim = unreal.load_asset(...):
   anim.set_editor_property('enable_root_motion', True)   # property name to verify in Python; same as the "Enable Root Motion" checkbox
   (optional distance tuning without re-authoring: a float curve named "RootMotionTranslationScale" on the montage.)
Frames A..B = the frames where the root bone translates (anim frame N = timeline frame N at rate 62.5/60). The offset persists (root motion is cumulative). PIE checks: leftover velocity at the end (last frame must have zero root delta; Mover friction may carry ~1 frame); scale fixed at 1.0 (BaseCombat.cpp:173) so distance is set by the anim; hitstop freezes it (good); the validator warns Timeline.RootMotionMix only with an Override Movement track (GSTN_CombatValidators.cpp:444-456).
No timeline-only route exists (1.A). Smallest C++ for "N cm between frames A and B" as timeline data: consume FGSTN_TimelineOutput::ActiveMovement in the combat tick / GA_BaseCombat and per frame queue a layered move (copy ExecuteRecoilMove, SimComponent.cpp:564) with velocity = Pose.TransformVectorNoScale(Curve->GetVectorValue(Frame-StartFrame)), zero on MovementEnds. Simpler: add float DistanceCm to the Movement track (constant speed = DistanceCm / ((EndFrame-StartFrame) * tick seconds), no curve asset). About 50-80 lines in GSTNCombatNP plus a text-import in the kit script.

## 3. Animation authoring
Root-motion route: the AnimSequence must CARRY the root translation, Enable Root Motion on; the capsule moves via the sim. Track route (needs the C++ consumer): the AnimSequence must stay IN PLACE, else both fight (RootMotionMix warning, GSTNCombatEditor/README.md:378). The project overrides no AnimInstance RootMotionMode (not found), so the engine default applies; confirm in PIE that the mesh is not double-moved. Whether the current V2 builds carry root travel: not stated anywhere (Tools/AnimPipeline cards use "travel" for limbs only).
