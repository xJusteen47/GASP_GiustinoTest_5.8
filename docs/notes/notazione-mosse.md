Sostituisce light/strong/smash di Smash.
- F.L = Forward Light. N.L = Neutral Light (jab). Cr.L = Cr.N.L = Crouched Light. Cr.F.L = Crouched Forward Light.
- Strong: "light" diventa "strong" (F.S, N.S, Cr.F.S). Special: diventa "special" (F.Sp, N.Sp).
- In aria: "Aerial" in fondo (F.L Aerial).
